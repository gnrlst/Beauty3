# HairFlow

Интерактивный прототип системы управленческого учёта волос по первой версии ТЗ.

## Запуск

Откройте `dist/index.html` в браузере либо раздайте папку `dist` любым статическим сервером. Зависимости и сборка не требуются.

## Реализовано

- Приёмка сырья с ценой в USD, сохранённым курсом и расходами.
- Карточки волос, поиск, производство, потери и автоматическая себестоимость.
- Перемещения, продажа партнёру, кабинет партнёра, его обработка и продажи.
- Частичные продажи, оплаты при продаже, положительные и отрицательные доли маржи.
- Этикетки Code 128, печать, CSV-выгрузки, история операций.
- Демонстрация ролей и помощник с ограниченным набором запросов.

Данные являются примерами и сохраняются в localStorage конкретного браузера. Роли являются демонстрацией интерфейса, не механизмом безопасности. Серверная база, аутентификация, Telegram и голос, отдельные платежи, возвраты, разделение/объединение волос и полноценный граф ещё не реализованы. Прототип нельзя использовать как защищённый производственный учёт.

## Проверки

`node tests/engine.test.cjs`

Исходная экономика: маржа партнёра = выручка − стоимость проданных волос по цене передачи − прямые затраты на проданный объём. Доля начисляется независимо от оплаты. Общие расходы партнёра не уменьшают эту маржу.
